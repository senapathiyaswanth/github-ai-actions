# Support

## 🆘 Getting Help

### Before asking for help

1. Check the [FAQ](FAQ.md)
2. Search [existing discussions](https://github.com/github-ai-actions/github-ai-actions/discussions)
3. Review the [documentation](docs/)
4. Check [closed issues](https://github.com/github-ai-actions/github-ai-actions/issues?q=is%3Aissued+is%3Aclosed)

### Where to get support

| Type | Where |
| ---- | ----- |
| 💬 Questions & How-To | [GitHub Discussions — Q&A](https://github.com/github-ai-actions/github-ai-actions/discussions/new?category=q-a) |
| 🐛 Bug Reports | [GitHub Issues](https://github.com/github-ai-actions/github-ai-actions/issues/new?template=bug_report.yml) |
| ✨ Feature Requests | [GitHub Issues](https://github.com/github-ai-actions/github-ai-actions/issues/new?template=feature_request.yml) |
| 🔒 Security Issues | [Security Advisories](https://github.com/github-ai-actions/github-ai-actions/security/advisories/new) |
| 💡 Ideas & RFC | [GitHub Discussions — Ideas](https://github.com/github-ai-actions/github-ai-actions/discussions/new?category=ideas) |

### Response times

This is a community-maintained open-source project. Response times are best-effort:

- **Security issues**: Within 48 hours
- **Bug reports**: Within 1 week
- **Feature requests**: Reviewed in weekly triage
- **Questions**: Community-driven, no SLA
